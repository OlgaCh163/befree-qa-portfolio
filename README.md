# Befree QA Portfolio

QA portfolio project: manual testing of an e-commerce website.

## О проекте

Учебный проект по ручному тестированию интернет-магазина Befree.

В рамках проекта подготовлена тестовая документация и выполнена проверка основных пользовательских сценариев.
