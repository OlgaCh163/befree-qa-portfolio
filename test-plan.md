# Test Plan — Befree

## 1. Цель тестирования

Проверить основные пользовательские сценарии интернет-магазина Befree и убедиться, что ключевые функции работают корректно.

## 2. Объект тестирования

Веб-сайт интернет-магазина Befree.

## 3. Области тестирования

В рамках тестирования проверяются:

* главная страница;
* каталог товаров;
* поиск товаров;
* фильтрация товаров;
* карточка товара;
* корзина.

## 4. Виды тестирования

* функциональное тестирование;
* ручное тестирование;
* UI-проверка основных элементов;
* проверка сетевых запросов;
* проверка сообщений и поведения интерфейса.

## 5. Тестовое окружение

* Браузер: Google Chrome
* Версия: 152.0.7977.77
* Разрядность: 64-bit
* Тестовый стенд: веб-сайт Befree
* Доступ к интернету: необходим

## 6. Инструменты

* Qase — создание, хранение и выполнение тест-кейсов;
* DevTools — проверка консоли и сетевых запросов;
* GitHub — хранение тестовой документации проекта.

## 7. Основные тестовые сценарии

В рамках проекта проверяются следующие сценарии:

1. Поиск товара по названию.
2. Поиск несуществующего товара.
3. Применение фильтра.
4. Открытие карточки товара.
5. Добавление товара в корзину.
6. Удаление товара из корзины.

## 8. Критерии успешного тестирования

Тестирование считается успешным, если:

* основные пользовательские сценарии выполняются без критических ошибок;
* товары и информация о них отображаются корректно;
* выбранные параметры сохраняются корректно;
* добавление и удаление товаров из корзины работает корректно;
* интерфейс не содержит критических проблем, препятствующих использованию сайта.
