# Test Cases — Befree

## BF-001 — Поиск товара по названию

**Предусловие:** открыта главная страница Befree.

**Шаги:**

1. Открыть главную страницу Befree.
2. Найти поле или иконку поиска.
3. Ввести существующий товар, например «футболка».
4. Выполнить поиск.

**Ожидаемый результат:** отображаются товары, соответствующие поисковому запросу.

## BF-005 — Добавление товара в корзину

**Предусловие:** открыт доступный товар.

**Шаги:**

1. Открыть карточку товара.
2. Проверить доступные размеры или обязательные параметры.
3. Выбрать доступный размер.
4. Нажать кнопку добавления в корзину.
5. Открыть корзину.
6. Проверить название, размер и цену товара.

**Ожидаемый результат:** товар успешно добавляется в корзину, а информация о нём соответствует данным карточки товара.

## BF-006 — Удаление товара из корзины

**Предусловие:** в корзине находится добавленный товар.

**Шаги:**

1. Открыть корзину.
2. Проверить информацию о товаре.
3. Найти элемент управления для удаления.
4. Удалить товар.
5. Проверить содержимое корзины.
6. Проверить количество товаров и итоговую стоимость.

**Ожидаемый результат:** товар удаляется из корзины, количество товаров и итоговая стоимость обновляются корректно.
